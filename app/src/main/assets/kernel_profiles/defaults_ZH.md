# 公共执行默认值

这些值保持 S03 迁移前行为。时间字段的单位由后缀决定：`_ms` 为毫秒，`_us` 为微秒。S08 才会把它们接到原生调用点；在此之前它们用于稳定结构定义和未来覆盖。

## 推荐核心

### `recommended_cpus.main`

- 默认值：`0`
- 作用：推荐主竞态线程核心。
- 影响：改变调度、热量与竞态窗口；界面显式选择优先。
- 默认理由：兼容旧的 0/1 回退且不假设设备拓扑。

### `recommended_cpus.consumer`

- 默认值：`1`
- 作用：推荐消费者核心。
- 影响：与主核心同核会增加互相抢占；不存在的核心会失败或回退。
- 默认理由：与主核心分离并保持旧默认。

## 堆准备

### `heap.prepare_max_attempts`

- 默认值：`4`
- 作用：堆准备的完整重试上限。
- 影响：增大可提高偶发恢复率，也增加耗时和温升。
- 默认理由：原实现最多四轮，迁移时保持行为。

### `heap.prepare_timeout_ms`

- 默认值：`240000`
- 作用：单次堆准备总超时。
- 影响：太短会误判慢设备；太长会延迟失败反馈。
- 默认理由：4 分钟覆盖旧最坏路径且仍有上界。

### `heap.kernelsnitch_timeout_ms`

- 默认值：`60000`
- 作用：KernelSnitch 扫描等待上限。
- 影响：缩短可能漏掉结果，增大会延长卡住状态。
- 默认理由：原扫描窗口为 60 秒。

## 共享竞态时序

### `race.route_wait_ms`

- 默认值：`1000`
- 作用：路线启动前共享等待。
- 影响：影响线程/对象就绪顺序。
- 默认理由：1 秒是旧实现的保守稳定窗口。

### `race.setup_settle_us`

- 默认值：`50000`
- 作用：竞态准备后的稳定等待。
- 影响：太短会在资源未就绪时触发。
- 默认理由：原 50 毫秒平衡可靠性和速度。

### `race.state_poll_interval_us`

- 默认值：`1000`
- 作用：共享状态轮询间隔。
- 影响：越小处理器占用越高，越大响应越迟。
- 默认理由：1 毫秒保持旧轮询粒度。

## W1/W2/W3 阶段

### `stages.w1_attempts`

- 默认值：`15`
- 作用：W1 写入尝试上限。
- 影响：增大提高机会但累积热量和破坏风险。
- 默认理由：来自原 W1 循环常量。

### `stages.w1_settle_us`

- 默认值：`100000`
- 作用：W1 每轮后稳定等待。
- 影响：决定验证前是否给内核状态足够时间。
- 默认理由：原实现使用 100 毫秒。

### `stages.w1_scratch_repair_attempts`

- 默认值：`3`
- 作用：W1 临时区修复次数。
- 影响：更多修复可能恢复状态，也可能重复触碰损坏对象。
- 默认理由：原实现限制三次。

### `stages.w2_attempts`

- 默认值：`15`
- 作用：W2 凭证写入尝试上限。
- 影响：影响提权成功机会、耗时和风险。
- 默认理由：与旧 W2 循环一致。

### `stages.w2_settle_us`

- 默认值：`100000`
- 作用：W2 每轮后等待。
- 影响：太短可能在凭证尚未可见时验证。
- 默认理由：保留旧 100 毫秒。

### `stages.w3_chain_rounds`

- 默认值：`3`
- 作用：W3 整链重复轮数。
- 影响：增大能覆盖偶发失配但延长高风险阶段。
- 默认理由：原流程最多三轮。

### `stages.w3_attempts`

- 默认值：`6`
- 作用：每轮 W3 尝试数。
- 影响：影响 seccomp 绕过机会与线程压力。
- 默认理由：保留原六次上限。

### `stages.w3_settle_us`

- 默认值：`50000`
- 作用：W3 尝试后等待。
- 影响：控制验证时序和速度。
- 默认理由：原实现使用 50 毫秒。

## TCP 零拷贝路线

### `routes.tcp_zerocopy.attempts`

- 默认值：`2000`
- 作用：TCP 零拷贝路线爆破上限。
- 影响：最大温升/耗时贡献之一；过低会降低命中率。
- 默认理由：等于原路线硬编码上限。

### `routes.tcp_zerocopy.arm_sequence`

- 默认值：`16`
- 作用：准备阶段序列长度。
- 影响：改变喷射/触发排列，错误值会错过窗口。
- 默认理由：保留已验证的 16 步序列。

### `routes.tcp_zerocopy.post_receive_hold_iterations`

- 默认值：`20000`
- 作用：接收后忙等保持次数。
- 影响：增大保持窗口同时增加处理器热量。
- 默认理由：迁移原忙等常量，避免改变窗口。

## Select 栈路线

### `routes.select_stack.enter_delay_us`

- 默认值：`50000`
- 作用：消费者进入后、主 select 触发前延迟。
- 影响：直接平移 select 栈竞态窗口。
- 默认理由：已验证旧值为 50 毫秒。

### `routes.select_stack.timeout_us`

- 默认值：`200000`
- 作用：单次 select 超时。
- 影响：太短提前退出，太长拖慢失败恢复。
- 默认理由：保持原 200 毫秒。

### `routes.select_stack.consumer_max_calls`

- 默认值：`1`
- 作用：消费者最大调用数。
- 影响：多次调用改变原单次触发布局。
- 默认理由：当前稳定路径只调用一次。

### `routes.select_stack.consumer_burst_calls`

- 默认值：`1`
- 作用：每批消费者调用数。
- 影响：增大批量会改变调度和栈存活时间。
- 默认理由：维持单调用批次。

## 多播等待者路线

### `routes.multicast_waiter.ready_timeout_ms`

- 默认值：`10000`
- 作用：多播等待者就绪超时。
- 影响：太短误判慢调度，太长延迟清理。
- 默认理由：原上限 10 秒。

### `routes.multicast_waiter.post_requeue_settle_us`

- 默认值：`200000`
- 作用：重新入队后稳定等待。
- 影响：影响等待者链稳定性；缩短可能过早改写。
- 默认理由：保留原 200 毫秒。

### `routes.multicast_waiter.post_adjust_settle_us`

- 默认值：`100000`
- 作用：调整等待者后等待。
- 影响：影响后续读写观察到的结构状态。
- 默认理由：保留原 100 毫秒。

## 提权交接

### `handoff.pre_dispatch_settle_ms`

- 默认值：`2000`
- 作用：向 KernelSU 交接前等待。
- 影响：太短可能在权限/SELinux 状态未稳定时启动。
- 默认理由：原流程等待 2 秒。

### `handoff.module_poll_attempts`

- 默认值：`30`
- 作用：模块加载状态轮询次数。
- 影响：与间隔共同决定 3 秒总窗口。
- 默认理由：30×100 毫秒保持原 3 秒。

### `handoff.module_poll_interval_ms`

- 默认值：`100`
- 作用：模块轮询间隔。
- 影响：更小增加唤醒，更大降低响应。
- 默认理由：原粒度 100 毫秒。

### `handoff.enforce_poll_attempts`

- 默认值：`200`
- 作用：强制状态轮询次数。
- 影响：与间隔共同决定 20 秒恢复窗口。
- 默认理由：200×100 毫秒保留原 20 秒。

### `handoff.enforce_poll_interval_ms`

- 默认值：`100`
- 作用：强制状态轮询间隔。
- 影响：影响检测延迟与处理器唤醒。
- 默认理由：原粒度 100 毫秒。

任何改动都应记录设备、温度、核心组合、成功率和失败阶段。
