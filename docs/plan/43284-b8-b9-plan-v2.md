- 日期：2026-10-19
- 用户裁定：payload 脚本由 UI 检测/生成；Lua 自由反射；不引入 Payload/Manager 适配类。
- 结论：删除 B8 设计中的 PayloadScriptSpec/Renderer/ManagerSelector/ManagerSpec/CustomKo/LuaPayloadAdapter/PlatformPlan。

## 为什么删

现有 UI 已经有：

~~~text
FinishScript.toRootScript
FinishScriptStore -> files/finish/run.sh
FinishConfig/PayloadRequests -> manager/app/cmd/lkm
~~~

引擎再建一套 Payload/Manager 类就是第二份权威。
Lua 以后通过反射调用现有函数，不需要稳定适配接口。
