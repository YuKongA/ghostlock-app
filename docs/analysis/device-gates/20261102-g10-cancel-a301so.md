## 变更
- `AppProcessFlowLauncher`：轮询改为可取消 `ensureActive()+delay(100ms)`；`CancellationException` ⇒ `host.cancel()` 后 rethrow；finally 清理顺序不变。
- `ShizukuFlowHostClient`/`ShizukuProcessFlowLauncher`：同样可取消（`cancelFlow()` + rethrow）；取消路径回写 `lastHostPid`（client 已启动 host 时）。
- `DiagnosticFlowEntries.DiagnosticSlowFlow`：20s（100ms tick）慢 flow，`env.isCancelled()` ⇒ `Failed("diag:cancelled")`；仅 debug registry 可解析。
- `FlowHostCancellationTest`：等首个 `diag:slow:tick:`（≤10s）再取消；Shizuku preflight 加强为 `pingBinder && permission && uid==2000 && domain contains u:r:shell:s0`，不满足 skip 且 reason 含实际值。
