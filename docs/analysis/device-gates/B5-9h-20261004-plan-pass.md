## 说明：上游方案为何在本机可行

上游 `elf_parser.c:47` 用 `payload_target = p_offset + p_filesz` 且不检查余量；该地址位于**按页取整的可执行映射尾区**（本机 exec LOAD `filesz == memsz == 0x798c8`，但映射到 `0x100000`；下一 RW LOAD 的 vaddr 从 `0x106628` 起，中间 `0x4000` 空洞）→ 2520 B 可用。我们此前用 `p_memsz - p_filesz` 判余量得 0，属实现过严，已修正（`B5-9h-2`）。
