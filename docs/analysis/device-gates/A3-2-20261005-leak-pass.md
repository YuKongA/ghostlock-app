## 判定

1. **泄漏语义不变**：`mm_struct` 为 canonical direct-map VA（`0xffffff8a…` / `0xffffff89…`，与 `direct_map_end=ffffff8a80000000` 同域），
   `prepare_kernel_page ok attempt=1` 说明新 `AddressDiscoveryOps` 路径成功且被消费；
2. **全链不受影响**：multicast 单 route 命中、`child is root`、handoff、KernelSU ready、SELinux 收尾 Enforcing；
3. **无持久性破坏**：AVB 12/0 + 文件级 CONSISTENT（43499 走内核内存，不动页缓存，符合机制）；
4. **有意观察差异**（设计 §3.9 已记录）：成功路径日志现打印 **canonical VA**（原为 tagged raw）；失败路径仍 `0xffff…ffff`。
5. **panic 归因**：同一二进制「panic → 冷机复跑 PASS」→ 与 A3-2 item 3 无因果，属 `KERNEL-PANIC-01`。
