`core/src/main.cpp` 的 `read_document` 原先经 stdio 读取，其缓冲会**越过文档边界**，把紧随其后的会话帧一并取走，使帧读取器看到空流。现在改为**裸读**：文档之后有可选帧，读文档的一方必须恰好停在边界。这一处**不是临时物**。
