**结论（内核域）**：`sample_type=262145`（IP|REGS_INTR）确实投递 **280B record、32×8B 寄存器**
（sp 为内核栈 VA）；**B1 修复被内核层验证**。2026-10-08「24B/ABI=0 无寄存器」确为探针
`1<<14`(WEIGHT) 位写错（finding 已修正）。shell 域 self/child open 均成功（uid=2000）。

**新发现 G1-2（实现缺口，需后续批）**：该内核把 ABI 字段报为 **2**（legacy `ops.cpp:487`
是 `abi==1||abi==2` 都按 8B regs 读）；当前 Kotlin parser 对 ABI=2 返回
`perf-sample-abi32-unsupported`（`Cve43499PerfSampleParser`）。若未来 App/root 路径启用，
会误拒绝本设备全部有效样本 ⇒ 应改为接受 ABI=1/2 且按 280B/8B regs 解析并加回归向量。
**本任务不改生产 parser**（行为变更需设计/批准）；已上报 Lead。
