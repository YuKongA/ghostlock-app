# N3 page send through native fd · 2026-10-20 10:43

- 设备：`Pixel_5(AVD) - 13`
- 命令：`./gradlew :app:connectedDebugAndroidTest -Pandroid.testInstrumentationRunnerArguments.class=com.ghostlock.app.N3PipeInstrumentedTest`

## 原始读数

```text
n3-pipe=Ok(waiterResult=0, waitResult=0, ownerResult=0, requeueResult=1,
  actorsStarted=true, pageStage=1, pageErrno=0, pageBytesWritten=16384,
  joinTimedOut=false, elapsedNs=1403792)
read=Ok(value=16384)
```

## 判读

- Kotlin 生成 16 KiB 页，`NativeAttemptParams.pageFd` 指定管道写端；
- C++ `run_attempt` 通过 `write(fd, page, len)` 把页送出，回读 16384 字节且内容一致；
- 随后 actor batch `requeue=1`/`wait=0`；
- 这是 page-send 通道，不是内核 page landing；没有 root。

## 结论

页发送路径（Kotlin 页 → native fd → actor）已通；production shaping socket fd 由 prepare 提供后即可替换管道。
