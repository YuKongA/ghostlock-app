# Lua 暴露面设计（绑定面 = **实际暴露什么就绑什么**）

> 分析类（≤8 KiB）。**自包含**。**口径（用户 2026-10-08 修正）**：绑定面**不是**「只能 `contract`」，而是「**我们实际暴露什么就绑什么**」⇒ 先有**暴露面表**（唯一权威），再按表绑定；**表外名字 ⇒ 具名拒绝**。

## §1 暴露面表（**唯一权威**；表外名字一律拒绝）

| 条目名 | 形态 | 参数界 | 语义 | 实现层 | **stage 期** | 执行期 | 相位归属 | 持资源 | 拒绝码 |
|---|---|---|---|---|---|---|---|---|---|
| `backend(id)` | 函数 `(id:str) → backend 句柄` | `id ∈` 目录 token 集 | 取 backend 句柄（仅作后续条目接收者） | 组合根 / 目录 | 允许（只记录） | 允许 | **否** | 否（句柄=目录项） | `surface-unknown-token` · `backend-not-available` |
| `b:writeop{target, value, width?}` | 句柄方法（table 参数） | **`target ∈ profile 符号名`** · `value` 整数 · `width? ∈ {1,2,4,8}` | **窗口内原子写**（park → write → release 由实现层一次完成）；**相位 = 运行时内部** | backend route / step | 允许（stage 记录） | 允许 | **窗口相位**（运行时内部分组） | 否（句柄只标识） | `param-invalid` · `geometry-missing` · `op-not-available` |
| `b:settle{us}` | 句柄方法 | `us` 整数 ≤ profile 参数上界 | 时间等待（**参数化**；不得用 C++ 默认值兜底） | `support/timing` | 允许 | 允许 | **是**（值由参数化控制） | 否 | `param-invalid` · `param-missing` |
| `b:handoff{terminal}` | 句柄方法 | `terminal ∈` 目录 token 集 | 交接给 terminal（exec 列表 + **三层收尾**） | terminal / handoff | 允许 | 允许 | **否** | 否 | `surface-unknown-token` · `executor-unavailable` |
| **`cfg`**（只读快照） | 表（快照） | 字段 ∈ manifest 声明集合 | **脚本可读的只读快照**（取代 `profile.get`） | profile 层（快照注入） | 允许 | 只读允许 | 否 | 否 | `cfg-unknown-field` |
| 语言级循环 / 条件（`for`/`while`/`if`） | **语言结构**（非条目） | 迭代次数受**预算**约束 | 控制流（录制可展开、重放须一致） | Lua 沙箱 | 允许 | 允许 | **否**（窗口内零 Lua） | 否 | `budget-exceeded` |
| **表外任意名字** | — | — | — | — | **拒绝** | **拒绝** | — | — | **`surface-unknown-name`**（附 `path` 与 hint） |

- **列语义**：**实现层** = 该条目落到哪一层；**stage 期/执行期** = 单遍执行（§3）的两段各自是否放行；**相位归属** = 该条目属于**运行时内部相位分组**（**不是**脚本可见的分组手段）；**持资源** = 是否使脚本持有 C++ 资源（**一律否**）。
- **「窗口级 op」已降为运行时内部**：脚本**不再**表达窗口/非窗口分组；窗口相位由**实现层**按条目类型内部分组（`writeop`/`settle` 属之，其余不属）。
- **删除 `profile.get`**（被 **`cfg`** 取代）：`cfg` 为**只读快照**（stage 前注入），脚本只能读字段。

## §2 绑定权威（**单一名单**）

- **表的持有者**：**新契约层的 `surface` 表**（编译期 `constexpr`）——**唯一权威**；Lua 宿主**按表注册**，**不注册表外名字**（注册集合 ≠ 表 ⇒ 启动期即失败）。
- **机器判据（无第二名单）**：① 宿主**注册集合 == 表**（逐项断言，缺一/多一即失败）；② 全仓 grep：每个条目名**只在该表定义一次**（其他处为引用）；③ 沙箱**符号级证据**：表中未列的任何库/名字在产物中不存在（未注册）。
- **判据形式**：表外调用 ⇒ **具名拒绝** `surface-unknown-name`（**默认拒绝**，不做近似匹配）。
- **与「实际暴露」的一致性**：表的写与绑定的写**必须同源**（同一处表驱动生成绑定）；「先写绑定再补表」视为违例。

## §3 单遍执行（**跑脚本 → stage → gate 校验 → 按相位执行**）

1. **跑脚本（一次）**：脚本只在**窗口外**运行一次，产出 **staged 计划**（有序条目 + 参数）——「把脚本意图**冻结**为计划产物」。
2. **gate 校验（对象 = staged 计划）**：`plan_gate` 十条判定 + **surface 表校验**（名字/参数界）**针对 staged 产物**执行；**不重跑脚本**。失败 ⇒ 具名拒绝（**不进入执行**）。
3. **执行（按相位）**：按 staged 计划**按相位**执行（窗口相位 / 非窗口相位由**实现层内部分组**）；**脚本不参与执行**。

- **逐调用边界校验（保留）**：执行期每次条目调用仍做**边界校验**（参数界/句柄/相位）；越界 ⇒ **具名拒绝 + 立即终止**。
- **判据（三条，可证伪）**：
  - **stage 零副作用**：stage 期不得出现写系统调用/资源获取（证据 = 符号级 + 运行期观测；出现即缺陷）；
  - **确定性**：同输入**两次 stage 逐字节相同**（含条目序与参数）；
  - **staged == 执行**：执行逐条对应 staged 计划的条目与参数（**逐值相同**）；偏差 ⇒ **立即终止**并记为缺陷。

## §3.1 纪律放宽记录（**强制越权，TD-RW2-1**）

- **用户裁定**：**「用户脚本正确性 = 用户责任」**。
- **放宽**：**不再**为脚本**逻辑错误**做静态证明（不要求证明「顺序/取值在语义上正确」）。
- **保留（不放宽）**：**窗口内零 Lua** · **逐调用边界校验** · **gate 校验 staged** · **预算**（指令/内存/64 KB）。
- **代价（如实）**：用户脚本改坏时**可能 panic**（视为已知风险，不在本层拦截）。
- **技术债**：**`TD-RW2-1`**；**偿还时机 = 首个真机门禁（G2）后复评**（按真机证据决定是否加回部分静态检查）。

## §4 资源与窗口

- **句柄边界**：脚本只在**表内条目**上持句柄（`backend(id)` 的返回）；句柄 = **POD** `{kind,index,generation}`、**有界 64**、**无 `__gc`**（[ADR-0010](../analysis/adr/0010-lua-cpp-resource-model.md)，**待批**）；脚本**不得**自造/延长/跨域使用句柄。
- **窗口内**：**脚本本身在窗口内不执行**（窗口内零 Lua）；窗口相位动作由实现层按 **staged 计划**执行（`writeop`/`settle`）；其余条目**不得**出现在窗口相位。
- **资源归属**：窗口作用域资源由**窗口宿主**独占（RAII 逐退出路径回收），脚本**只持句柄**；缺参数 ⇒ **具名拒绝**（不得 C++ 默认兜底，见 [rewrite-plan-v2](../plan/rewrite-plan-v2.md) §3）。

## §5 取代关系（**沿革不删**）

| 旧表述 | 新表述（本文） | 沿革 |
|---|---|---|
| P5 规格：**计划 = `return` 表** | **计划 = 脚本（stage 出计划）** | 脚本仍是**顺序唯一权威**；产出形态由「返回表」改为「**staged 计划**」（表可作语法糖，语义以 stage 产物为准） |
| AGENTS：`available{route, queue}` | **`available` 列表**（每项 = `description` + **脚本**） | 菜单项不再携带 `route`/`queue` 字段；顺序与参数由脚本表达（queue 已退役） |

- **保留**：旧表述与决策（D22/D30/D31、R11 选 C）**不删**；本节只标注**取代关系**。
