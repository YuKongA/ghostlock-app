## 3. 移植要点与修复记录

- **修复（红灯→绿）**：`params.c` 缺 `<stdlib.h>`（`strtoull` 隐式声明）→ 补 include；之后 0 warning/0 error。
- **常量参数化**：上游每构建 `#define`（`STATIC_TIMER_SITE`/`CRED_*`/`TASK_ALLOC_*`/`SELINUX_*`/`ROOT_USER` 等）→ `params.h::struct glk98260_params`（26 数值 + 4 字符串），argv `--params`；`params.c` 严格解析/边界校验（字符集、低 21 位、VA 窗口、sizes/offsets 上限、`--allow-shell` 必须），失败打印 `GLK98260_PREFLIGHT=fail:<reason>` 后退出（**未 armed**）。
- **marker**：`GLK98260_ENV/PREFLIGHT/ARMED/SELINUX_OFF/PANIC_ON_WARN/FAKE_CRED/FAKE_UID/PARKED`；`ARMED` 在首次释放 `timer_go` 前（唯一不可逆点）；`park_forever` 打印 `PARKED=<reason>` + 保留上游 `parking without reap`。
- **fake 链顺序重排（与上游相反）**：`SELINUX_OFF → panic_on_warn → FAKE_CRED → FAKE_UID`（避免 `panic_on_warn=1` 在 sysctl 可写前硬 panic）。
- **exec-self 语义保留**：`argv[0]==""→_exit(42)` 提前到参数解析前；child re-exec 参数改为 `--params <S> wait <mode>`；target 空 argv 不解析 params。
- **KSU 脚本参数化**：manager 包名/KMI/late-load args/ksud fallbacks 从 profile 注入，脚本仍做 `pm path`→`lib/arm64/libksud.so`→`late-load`→`/proc/modules` 判据→恢复 enforcing。
- **诊断模式仅 Debug**：`GLK98260_ENABLE_DIAGNOSTIC`（CMake 仅 `CMAKE_BUILD_TYPE=Debug` 定义）；release 只保留 `fake`。
- **`--setsid` fallback**：JNI `POSIX_SPAWN_SETSID` 不可用时由 payload 自建会话（仅非 `wait` 顶层进程）；TD-15。
- **静态守卫规则（R5-09）**：只禁**目标内核特定绝对地址**；通用 VA 窗口常量（`0xffffff0000000000`/`0xffffffc000000000`）为 allowlist。
- **不可逆语义保留**：失败即 park、不 reap、不 kill；fake 成功也 park（持有 fake cred 页）。
