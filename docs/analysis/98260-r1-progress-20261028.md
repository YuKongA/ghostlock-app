## 1. 最终执行结构（R1 落地）

```text
app Flow98260Impl（唯一 run 权威；validate→prepare→start→poll→verify→acceptance）
  → 公用 Shizuku host（GhostlockUserService + AIDL）
  → Cve98260ShizukuHost → service RemoteExecutor（预检/journal/暂存 payload+finish 脚本）
  → **公用 core/victim.VictimScriptLauncher**（spawn helper + execScript；backend 只给脚本/pid 探针）
  → Cve98260VictimLauncher → core/victim VictimSession（helper libghostlock_victim_helper.so，shell 域）
      → helper execScript(启动脚本) → 脚本后台启动 payload（日志/pid 落 /data/local/tmp）→ 脚本 exit
  → payload 内 fake-cred **rooted victim（child）直接 execve(/system/bin/sh, finishScript)**
  → service verify() 读 /proc/modules + finish marker/script sha/uid/SELinux/ksud → app 对拍证据
  → app 落 BootSafetyStore（成功也 must_reboot=true）→ unbind
```

**安全不变量**：helper 的 `execScript` 超时只 kill **启动脚本**（秒级退出），**绝不 kill payload**；payload 是脚本后台子进程、与 helper 解耦。finish 由 rooted victim 执行（不是 payload parent，也不是 app/su）。

## 8. 执行体口径（2026-10-28 用户裁定）

- **backend 只声明 uid 需求，不自检**：`BackendSpec.uidRequirement`（默认 `ANY_UID`→lua/43499/43284；98260→`SHELL_UID_2000`）。
- **UI 控制启动/拒绝**：UI 只看「执行体种类 + Shizuku 授权二值」（App=app 攻击线程；Shizuku=已 ping+已授权），**不读取 uid**；`BackendRunGate` 比对声明，不满足→`backend_run_uid_requirement`，Shizuku 未授权→`backend_run_executor_unavailable`。backend/Flow 不自检；Lua 绕过不兜底。
