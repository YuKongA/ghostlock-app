# 43499 · 奇偶为何只能靠换地址（round 126）

## 算术到顶（决定下一步）

```
页面缓冲 = ORDER3 × 2 = 32768 × 2 = 0x10000（64 KiB）
page_value = payload_base + 0x100（判据要 ((page_value >> 16) & 1) == 1）
⇒ 64 KiB 之内所有地址的 bit16 **相同** ⇒ 奇偶**唯一**由 payload_base 决定 ✗
⇒ 一个 64 KiB 缓冲**不可能**同时给出两种奇偶 ⇒ 数据层面**没有**可调余地 ✓
⇒ ⇒ 因此奇偶只能靠"页面落在哪"来选 ✓ —— 这正是退役 quarantine（地址轮换）的根本原因 ✓
```
