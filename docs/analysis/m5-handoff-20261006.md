## Working rules learned today (all from real incidents)

1. Gradle gates must be serialised; only compile-level tasks may overlap.
2. Count artefacts, not directories, when judging what was produced.
3. Builds sharing a cache directory must be serialised (a real collision happened).
4. Read failures from the test XML, in full; log summaries are not counts.
5. Edit anchors must be semantic boundaries (function name, declaration, whole block), never
   text fragments or 'the next bracket'.
6. Do not put backticks inside the program strings of tool calls.
