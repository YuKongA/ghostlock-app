# Launcher route clarification transaction

## Changed route/field

`ExecutableProcessRouting.dispatch(route, app, shizuku)` is now the single branch point. `APP` invokes only `app`; `SHIZUKU` invokes only `shizuku`. Exceptions propagate, so uncertain Shizuku failure does not start a second App child. Route selection remains binder-reachable AND permission-granted => `SHIZUKU`; all other states => `APP`.
