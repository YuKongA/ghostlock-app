## A. 设计规则（§6.3 / §6.5）

| # | 规则 | 判据 | 违规处理 |
|---|---|---|---|
| R1 | **单一权威**：每个事实只有一处权威，其余为派生 | 同一事实的权威点唯一；派生由生成或对拍保证 | 停批，先收敛权威 |
| R2 | **一处读取**：任何数据只有一条读取路径 | 代码中该数据的读取点唯一；若并存 ⇒ 同批逐值等价对拍且声明仅作回退 | 视为缺陷，同批修 |
| R3 | 层间**只传数据**（数据耦合）；禁公共耦合/控制耦合/内容耦合 | 无新增可变全局；下层不读上层标志位；无跨模块内部结构窥探 | 设计评审否决 |
| R4 | 每个模块**功能内聚**（一个可命名功能，缺一不可） | 模块职责可一句话说清且不可再分 | 拆分 |
| R5 | 单文件 **200–400 行**（Hatton 最低错误密度区）；>600 行必须拆分或书面说明 | 行数统计 | 拆分或记债 |
| R6 | **编译期锁定**：组合→步骤集→终极端在编译期绑定；运行期只做声明符合性检查 | 无运行期语义推断分支 | 设计评审否决 |
| R7 | 层次结构图深度/宽度、扇入/扇出 **≤ 7** | 层次图核对 | 重新分解 |

## B. 实现规则（§7.2 / §7.3）

| # | 规则 | 判据 | 违规处理 |
|---|---|---|---|
| R8 | 写入**原子化**（临时文件 + 替换）；禁止就地改写 | 差异中无"直接覆盖目标文件" | 回退重做 |
| R9 | **产物可丢弃**：任何缓存/中间物可 clean 后重建 | clean 后判据全绿 | 修构建 |
| R10 | **守卫必须能失败**：新增守卫/断言须做一次证伪实验 | 报告含造错点 + 失败输出 + 撤回核验 | 视为无效守卫 |
| R11 | **具名诊断是契约**：阶段/原因标识一旦发布不得改义 | 诊断标识稳定；失败能答"哪层/哪个输入/哪个判据" | 按缺陷处理 |
| R12 | 失败处理**不得降级继续**（fail-closed） | 无"默认继续/自动换路/自动重试" | 设计评审否决 |
| R13 | 禁止新增 CLI/旁路；实验走生产路径（参数化/去限制） | 无可选实验开关 | 同批清理登记 |

## H. 职业行为（§1.10）

| # | 规则 | 判据 | 违规处理 |
|---|---|---|---|
| R34 | 如实报告：失败、未完成、无效读数一律标注，不得掩饰 | 报告含"未完成/无效"显式标注 | 视为严重违规 |
| R35 | 保密：运行时密钥/SPI/端口**永不入文档** | 文档无此类值 | 立即移除并复盘 |
| R36 | 授权边界：仅对用户授权设备操作；不滥用 | 操作有授权依据 | 停止操作 |
| R37 | **脚本块注释不得含 `/*` 序列**（Kotlin/Gradle 支持**嵌套**块注释） | 新增/改动 `*.gradle.kts` 后必须证明任务**已注册并被执行**（打印任务名 + 结果横幅），**不得只看 BUILD SUCCESSFUL**；`grep` 块注释文本不得出现 `/*`（如写 `docs/archive 目录` 而非 `docs/archive/**`） | 视为无效改动：任务静默不注册 = 门禁形同不存在，同批修 + 复盘 |

| R40 | **删除批次只含符号**（注释/证据文本不在删除范围） | 批次边界 = **符号声明与其实体**；**注释、证据文本、沿革句、文档引用一律不删**；确需改动注释/证据 ⇒ **必须举证并登记**（哪一条、为何、依据） | 超范围改动视为违规：回退该处 + 补登记 |
| R41 | **写回纪律：禁止「分块读 + 全文写回」**（**与体量无关的硬约束**） | ① **任何 `write` 的载荷不得来自带 `offset/limit` 的读**（窗口读只用于**查看**，不得作写回载荷）；**小修一律定点 `edit`**（`edit` 后需**重新整份读**方可再次编辑）；确需整份写回时，**写入前后各报一次 `totalLines` 与字节数**并与目标值比对；② **>50 KB 文件一律用定点 `edit`**，不得整份写回；④ **事故处置四步** = 先核 **HEAD 版是否等同编辑前状态**（`git show … \| wc -c` 比字节/行数）⇒ **只读导出到 `/tmp`**（禁工作树写回）⇒ **校验拼装字节数完全相等** ⇒ 写回后核行数与 `git diff --numstat` **+N/−0** | 视为无效改动：立即按④恢复并复盘（**本项因 2026-10-08 **两次**真实截断设立（第二次 = `full-process-uml.md` **11093 B → 713 B** 的窗口读整份写回 ⇒ **12 KB 文件亦中招**，故改为与体量无关）**：`full-process-uml.md` 63093 B/782 行 → **52031 B/601 行**；已**无损恢复**为 841 行、`+59/−0`） |
| R42 | **证伪实验有效性**（「没失败」不等于「断言无用」） | ① **打印改动后的原文**证明注入确实落盘（含行号/上下文）；② **跑会真正编译被测件的目标** —— 例：host 目标不含 `surface_test` 时必须跑 **`check`**（否则跑的是旧二进制/不含该件）；③ **stdout 与 stderr 同查**（错误可能只在其中一路）；④ **未失败时**，先证明「注入生效」「目标正确」「产物已重建」，**再**怀疑断言本身 | 视为无效证伪：结论作废、重做（**本项因 2026-10-08 连续 5 次无效证伪设立**：注入未落盘/目标不含被测件/只看一路输出/旧产物未重建） |
