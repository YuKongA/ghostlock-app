## 7. 补缺（P4 全部缺口）

- struct_size/abi_version 严格校验（请求/嵌套/输出三侧，见 abi §4）；负例：version=3、struct_size±1、未选 union 分支非零。
- reclaim：`reclaim_payload_size == 2*allocation_size` 且 ≤ staging_capacity；负例：2×+1。
- socket buffer 界：>0 且 ≤ 请求 max；负例 0/溢出。
- pselect `nfds ≤ min(max_nfds, FD_SETSIZE)`；负例 max_nfds=2048。
- identity∩scan：`[identity_start,identity_end)` 必须包含于 `[scan_lower,scan_upper)`；负例不交叠。
- staging/context：`2*allocation ≤ staging_capacity`、`prepare/spray/pre/post ≤ max_context_entries`；负例越界。
- 全部新阈值（1h/4MiB/2^26/999999999/1e6/2^26 disarm）**进请求字段**（placement.timeout/multicast_buffer/tcp_max_mapping/lock_pi_spin_ns/poll_settle/disarm_spin_limit），Native 只做“请求值 vs 请求上限”的自洽校验；负例逐项见 V 行。
- LEAK_TAG：nibble∈[0,15]、shift∈[0,63]、补 tag 后 ∈ scan 区间；ghost_pid>0、flag∈{0,0x80000000}、required∈{0,1}，0/失败=不做 disarm；requeue_expected i64∈[0,INT32_MAX]，作 CMP_REQUEUE_PI val3（显式收窄），测试断言期望值 0 与负例 -1/INT32_MAX+1。
