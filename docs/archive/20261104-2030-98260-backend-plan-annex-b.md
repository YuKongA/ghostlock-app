## N. 回滚安全步骤（I-16）

1. 若 `launch_pending || must_reboot` 或 helper 可能 parked ⇒ **禁止**清 prefs/删 `/data/local/tmp` 文件、禁止发信号；只提示"重启清理"。
2. 真重启（boot_id 变）后：清 prefs 键、删 staged helper/log；不动 KSU 状态。
3. 代码回滚：按主计划 §7 删除新增文件 + `edit` 逆改修改表（禁 `git checkout`）；记录回滚清单与时间。
4. 若已装 APK：卸载不清理 `/data/local/tmp`（shell 域文件），列入清理指引。
