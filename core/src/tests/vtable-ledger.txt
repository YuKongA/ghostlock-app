# Vtables the built binaries are allowed to contain, one symbol per line.
#
# This began as a blanket ban: the gate counted _ZTV symbols in four binaries and failed on any
# at all, because the window shape had to stay verifiable. The user ruling in ADR-0014 allows the
# virtual kernel access on the reasoning that virtual dispatch only enters the window and a call
# made outside it is safe, so the property to check is not that no vtable exists anywhere but
# that no vtable exists OTHER than the ones this project deliberately has.
#
# The list is empty because nothing in the scanned binaries has a vtable today. An entry is added
# for a type in the same change that introduces it, and an unexpected symbol fails the check with
# its name printed, so a vtable cannot arrive unnoticed.
